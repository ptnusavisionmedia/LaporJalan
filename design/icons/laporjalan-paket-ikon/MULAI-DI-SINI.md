# Aset ikon LaporJalan

## Ikon custom fitur utama

**buat-laporan-jalan-rusak.png** — ikon custom Buat Laporan Jalan Rusak, 512 × 512 px transparan. Master vektornya tersedia sebagai **buat-laporan-jalan-rusak.svg**. Menggabungkan pin lokasi, jalan retak, dan tanda tambah dengan warna logo aplikasi.

## Koleksi ikon fitur

1. **fitur/index.html** — buka katalog untuk mencari dan melihat seluruh ikon.
2. **fitur/png/berwarna/** — PNG transparan 512 × 512 px untuk penggunaan sebagai gambar.
3. **fitur/svg/berwarna/** — master SVG yang tetap tajam ketika diperbesar.
4. **fitur/png/satu-warna/** dan **fitur/svg/satu-warna/** — varian satu warna.
5. **fitur/pratinjau.png** — seluruh ikon dalam satu lembar.
6. **fitur/PANDUAN.md** — aturan warna, ukuran, aksesibilitas, dan pemetaan fitur.
7. **laporjalan-icon.png** — logo utama aplikasi yang menjadi acuan tema.

Seluruh **91 desain ikon** telah diganti dengan konsep custom yang sama seperti **buat-laporan-jalan-rusak.png**: pin hijau, bidang krem, highlight melengkung, chevron, dan lencana kuning di kanan bawah. Simbol tengah dan tanda pada lencana mengikuti fungsi setiap fitur. Versi satu warna mempertahankan bentuk pin dan posisi lencananya.

Tersedia dalam 2 varian dan 2 format: total **364 file ikon individual**. Sepuluh kelompok mengikuti fitur aplikasi warga dan web admin: navigasi, akun, jenis kerusakan, foto/laporan, lokasi, status, komunitas, kontrol, informasi, dan sistem. File lama telah diperbarui pada lokasi dan nama yang sama.

Seluruh aset ada di folder ini; tidak perlu mencari file dari folder aplikasi. Aset belum dipasang ke tampilan aplikasi. File sumber hanya berada di fitur/source/ dan tidak perlu dibuka untuk menggunakan ikon.

Semua aset disimpan langsung di folder ini, tanpa ZIP. Buka fitur/index.html untuk melihat dan memilih ikon.
